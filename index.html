About

I'm a first-year D3 Informatics Engineering student at Politeknik Elektronika Negeri Surabaya (PENS). Most of what I build sits behind the screen: REST APIs, database schemas, authentication, and real-time systems that drive what an audience sees during a live event.

Before university I led the coding division of my high school's IT club for two years, writing the syllabus and teaching C++ competitive programming every week. That habit of turning what I know into a lesson is still how I learn best.

Right now I split my time between backend side projects, live broadcast production for PENS Esports, and learning cloud deployment and AI tooling.

Proposed

Sample curriculum I'd run: Backend Web Development with JavaScript

A 4-session study jam for students who know basic JavaScript. Every session ends with something running.

  1. 1. HTTP and your first REST API

    Requests, responses, status codes, routing with Express.js; build a small notes API and test it with an HTTP client.

  2. 2. Data that survives a restart

    PostgreSQL basics, modelling with Prisma, migrations, and CRUD; move the notes API onto a real database.

  3. 3. Who are you? Authentication

    Password hashing, JWT access and refresh tokens, protecting routes, and why refresh-token rotation matters.

  4. 4. Ship it and make it live

    Deploying to a serverless platform (Vercel) with environment variables, then adding a WebSocket channel for live updates.
