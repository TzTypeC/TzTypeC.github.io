BBO Token System

License-token REST API with device binding, deployed on Vercel

Context

A small service that issues and validates license tokens for a desktop client and tells the client when it needs an update. First written in Express.js, later migrated to Next.js API Routes for serverless deployment on Vercel.

What I built

  • 4 endpoints: create user, generate token (custom value and optional expiry), validate token, check client version.
  • Device binding: the first validation binds a token to a device ID; a different device gets HTTP 409, expired tokens are rejected.
  • Version gate: outdated clients receive an 'update required' response (code 426).
  • One consistent response shape across endpoints: valid, message, code, data.
