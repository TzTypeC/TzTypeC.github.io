BASCOM

Backend for a school alumni network, with identity verification

Context

A community platform for alumni of Bastyasaka (SMAN 3 Jombang). Alumni register, get verified as real graduates, and reconnect. I owned the whole server side while my teammate built the client.

What I built

  • REST API on Express.js 5 with an 11-model Prisma schema on PostgreSQL.
  • Authentication with JWT access tokens and refresh-token rotation, including detection of reused (already rotated) refresh tokens.
  • Alumni identity verification: student ID (NIS) lookup combined with Jaro-Winkler fuzzy matching on names, so small spelling differences still verify.
  • Redis cache for the onboarding flow.
  • As PM: split tasks between backend and frontend and set up the Git branching workflow.

Scope note

Stopped at prototype stage; never released to production.
